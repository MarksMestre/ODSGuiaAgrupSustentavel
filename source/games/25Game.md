# 25Game

*Área das Parcerias · jogo 25*

**Título:** Jogo do Quim dos ODS

| Campo | Valor |
| --- | --- |
| Nome do Jogo | Jogo do Quim dos ODS |
| Objetivos de Desenvolvimento Sustentável (ODS) | Todos os ODS |
| Objetivos | Os escuteiros observam os símbolos dos ODS durante um intervalo pré-definido (ex: 30 segundos). Em seguida a imagem é coberta e as equipas têm de listar de memória o número de ordem, título e cor exata do maior número de objetivos. |
| Duração e Participantes | **Formato:** Presencial ou Online<br>**Participantes:** Secção<br>**Duração:** 20 minutos |
| Material | Ícones impressos dos 17 ODS ou projeção digital |
| Instruções | <strong>Instruções para formato virtual:</strong><br><ol><li><strong>1.</strong> Primeiramente, deve-se explicar as regras do Jogo do Quim, que são: os participantes têm X tempo para memorizar quais os ODS que estão no próximo slide.</li><li><strong>2.</strong> No slide seguinte insere-se os diversos ODS.</li><li><strong>3.</strong> Posteriormente, retira-se o mesmo e os participantes devem identificar todos os ODS.</li><li><strong>4.</strong> Ganha a equipa que se lembrar de mais ODS que viu.</li></ol><br><strong>Instruções para formato presencial:</strong><br><ol><li><strong>1.</strong> Debaixo de uma lona deve-se colocar os ODS espalhados, podendo haver mais do que um de cada.</li><li><strong>2.</strong> De seguida, explica-se a cada uma das equipas as regras do jogo do Quim (Têm X tempo para memorizar quais os ODS que existem debaixo da lona).</li><li><strong>3.</strong> Depois chama-se as equipas à vez e levanta-se a lona por X tempo.</li><li><strong>4.</strong> Ganha a equipa que se lembrar de mais ODS que viu.</li></ol> |
