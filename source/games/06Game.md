# 06Game

*Área das Pessoas · jogo 6*

**Título:** Corrida da Saúde

| Campo | Valor |
| --- | --- |
| Nome do Jogo | Corrida da Saúde |
| Objetivos de Desenvolvimento Sustentável (ODS) | **ODS 3** (Saúde de Qualidade) |
| Objetivos | As patrulhas alinham-se. A cada pergunta médica respondida acertadamente, um elemento avança para o topo da fila até cruzarem a meta. Exemplos de perguntas: tempo mínimo de lavagem das mãos com sabão ($40-60\text{ s}$), dador universal ($\text{O}^-$), osso mais pequeno (estribo). |
| Duração e Participantes | **Formato:** Presencial<br>**Participantes:** Subunidades em estafeta<br>**Duração:** Variável |
| Material | Cartão de perguntas de suporte básico e anatomia |
| Instruções | <ol><li><strong>1.</strong> Define-se uma distância curta para ser percorrida por cada subunidade.</li><li><strong>2.</strong> Cada equipa forma uma fila na linha de partida.</li><li><strong>3.</strong> O animador faz uma pergunta aleatória (abaixo listada) a cada subunidade de cada vez.</li><li><strong>4.</strong> Por cada resposta certa, a equipa avança uma pessoa, indo do fim da fila para o início, até chegarem à meta.</li><li><strong>5.</strong> Por cada resposta errada, a equipa mantém-se no sítio.</li><li><strong>6.</strong> A equipa que chegar primeiro, ganha.</li></ol> |
