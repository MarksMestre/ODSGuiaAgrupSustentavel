# 05Game

*Área das Pessoas · jogo 5*

**Título:** Peixinho das Desigualdades

| Campo | Valor |
| --- | --- |
| Nome do Jogo | Peixinho das Desigualdades |
| Objetivos de Desenvolvimento Sustentável (ODS) | **ODS 5, 10** |
| Objetivos | Jogo de cartas onde os elementos recolhem quartetos temáticos. Cada carta descreve uma limitação ou contexto de inclusão (ex: autismo, celíaco, refugiado, discalculia, cadeira de rodas, baixos recursos económicos). Ao fechar o quarteto, o grupo lê e responde à questão orientadora de acessibilidade presente na carta. |
| Duração e Participantes | **Formato:** Presencial<br>**Participantes:** Até 8 elementos<br>**Duração:** 90 a 120 minutos |
| Material | Baralho de cartas temático com personagens |
| Instruções | <ol><li><strong>1.</strong> O objetivo do jogo é reunir o máximo de quartetos que conseguir, enquanto se trabalha na diversidade.</li><li><strong>2.</strong> As cartas são baralhadas e distribuídas pelos jogadores. É possível que alguns jogadores recebam mais cartas do que outros (referindo-se a pontos de partida desiguais na vida).</li><li><strong>3.</strong> Um jogador aleatório começa o jogo pedindo a outro jogador específico uma carta de uma categoria da qual possui pelo menos um cartão (tem de pedir a carta exata pelo nome da personagem).</li><li><strong>4.</strong> Caso o jogador tenha a carta, este deve entregá-la ao jogador que a pediu. Caso não tenha, é a sua vez de pedir um cartão.</li><li><strong>5.</strong> Quem conseguir obter um cartão novo pode voltar a pedir uma carta.</li><li><strong>6.</strong> Quando se fizer um “peixinho” devem ser lidas as 4 cartas e alto e as perguntas presentes nos cartões devem ser discutidas.</li><li><strong>7.</strong> O jogo acaba quando todos os quartetos estiverem completos. O jogador que tiver mais quartetos completos é o vencedor do jogo.</li></ol> |
